# TaskNest Frontend

This is the React/Vite frontend for the TaskNest Project Management Platform.

## 🎨 Tech Stack
- **Framework**: React 18
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **State Management**: React Context & TanStack Query
- **UI Components**: Radix UI / Shadcn UI

## 🛠️ Features
- **Modern Login Experience**: Dynamic slideshow and floating glassmorphism UI.
- **Premium Buttons**: Custom animated buttons with liquid hover effects.
- **Micro-interactions**: Specialized SVG animations for task deletion and project creation.
- **Responsive Design**: Fully mobile-optimized layout.

## 🚀 Running Locally
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. The app will run on `http://localhost:8080`.

## ☁️ Deployment
This folder is deployed as a standalone service on Railway or Vercel. 
**Environment Variables Required:**
- `VITE_API_URL`: The URL of your deployed backend API.
